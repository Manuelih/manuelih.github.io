# Portfolio di Emanuele (Manuelih)

Sorgente del mio portfolio personale, online su [manuelih.github.io](https://manuelih.github.io).

Sviluppatore full-stack, 20 anni: plugin Minecraft enterprise (Paper/Spigot/Velocity, Java 21), bot Discord (discord.py, discord.js v14), sviluppo web (Node/Express, Next.js) e automazione (Python).

## Struttura

Sito statico multi-pagina, vanilla HTML/CSS/JS — nessuna dipendenza esterna oltre ai Google Fonts.

- `index.html` — Home
- `progetti.html` — Tutti i progetti, filtrabili per categoria
- `progetto-*.html` — Pagina di dettaglio per ciascun progetto
- `chi-sono.html` — Chi sono, percorso, competenze
- `contatti.html` — Contatti, form (mailto), FAQ
- `styles.css` — Design system condiviso
- `app.js` — Interattività: nav, reveal, filtro progetti, form, i18n
- `i18n.js` — Contenuti bilingue IT/EN

I progetti mostrati sono reali ma sviluppati per client e community private: sono descritti nel dettaglio senza link diretti, dato che il codice non è mio da pubblicare (vedi le FAQ nella pagina Contatti).
