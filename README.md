# mqnuu — portfolio

Portfolio personale di Emanuele (mqnuu), online su [manuelih.github.io](https://manuelih.github.io).

Pagina unica in HTML, CSS e JS vanilla, senza build e senza dipendenze oltre ai Google Fonts.

- `index.html` — struttura e testi italiani
- `styles.css` — stile (tema scuro, accento rosso `#ff3b3f`)
- `app.js` — progetti, traduzione EN, filtri, schede di dettaglio, animazioni

Per provarlo in locale:

```bash
python -m http.server 5173
```
