01
chi sono

    

      

        
Ho iniziato nel 2022. All'inizio mi seguiva un ragazzo che i plugin li scriveva già, il resto l'ho imparato da video su YouTube e provando tutto sul mio server di test.

        
Il primo plugin che ho finito era un mio Essentials fatto in casa: /gmc, /gms, /fly, /heal, /tp. Niente di che, ma funzionava e l'avevo scritto io. Poi sono arrivati i primi lavori per server di amici, e da lì sistemi sempre più grandi: kit, economie, fino al core completo di un server prison.

        
Oggi lavoro soprattutto con server roleplay: core a moduli, plugin su misura e mod Fabric e Forge. Il lavoro migliore è quando il server è pieno e nessuno si accorge del mio codice, perché semplicemente va.

01~/core

        
Core modulari

        
La base di tutto il server: un core che gestisce database, cache, comandi e messaggi, e ogni sistema in un modulo a parte. Aggiungi o aggiorni un pezzo senza toccare gli altri.

        
    
          
  • API interne versionate per tutti i moduli
    • 
          
  • Database asincrono con cache, niente lag sul main thread
    • 
          
  • Reti con proxy Velocity e più server
    • 
        

        
PaperVelocityMariaDBRedis
